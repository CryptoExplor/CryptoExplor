I design and ship automation-first infrastructure — tools that execute on-chain actions, surface market data, coordinate agents, and reduce repetitive workflows.

- **Farcaster Mini Apps** — production-ready social and onchain experiences

## Flagship Projects

### FarSend — Multi-chain Batch Sender

[![Repo](https://img.shields.io/badge/GitHub-FarSend-181717?style=flat&logo=github)](https://github.com/CryptoExplor/FarSend) [![Stars](https://img.shields.io/github/stars/CryptoExplor/FarSend?style=flat&color=success)](https://github.com/CryptoExplor/FarSend) [![Live](https://img.shields.io/badge/Live%20on-Farcaster-8A63D2?style=flat)](https://farcaster.xyz/miniapps/8BszfIpBviDs/farsend)

Batch-send ETH and ERC-20 tokens from one interface with CSV/JSON import, address validation, and gas-optimized contracts. Available as a Farcaster Mini App and at [farsend.vercel.app](https://farsend.vercel.app).

**Stack:** `JavaScript` `Web3` `Base` `EVM` `Farcaster`

### FarmLabs — On-chain Behavior Simulation Engine

[![Repo](https://img.shields.io/badge/GitHub-farmlabs-181717?style=flat&logo=github)](https://github.com/CryptoExplor/farmlabs) [![Stars](https://img.shields.io/github/stars/CryptoExplor/farmlabs?style=flat&color=success)](https://github.com/CryptoExplor/farmlabs) [![Live](https://img.shields.io/badge/Live-Cloudflare%20Pages-F38020?style=flat&logo=cloudflare&logoColor=white)](https://farmlabs.pages.dev)

Local-first Web3 automation suite for EVM testnet testing and research. Simulates persona-driven wallet behavior with randomized timing, multi-wallet orchestration, and analytics.

**Stack:** `JavaScript` `Ethers` `EVM` `Automation`

### VOIDMASKS — Permissionless On-chain NFT Collection

[![Repo](https://img.shields.io/badge/GitHub-VOIDMASKS-181717?style=flat&logo=github)](https://github.com/CryptoExplor/VOIDMASKS) [![Stars](https://img.shields.io/github/stars/CryptoExplor/VOIDMASKS?style=flat&color=success)](https://github.com/CryptoExplor/VOIDMASKS) [![Live](https://img.shields.io/badge/Live-Vercel-000000?style=flat&logo=vercel&logoColor=white)](https://voidmasks.vercel.app)

A 10,000-supply NFT collection on Stacks with deterministic, 100% on-chain SVG generation, seven traits, a free one-per-address mint, and no IPFS dependency.

**Stack:** `JavaScript` `Clarity` `Stacks` `Bitcoin L2`

### Wallet Forge — Client-side Wallet Data Preparation

[![Repo](https://img.shields.io/badge/GitHub-Wallet--Forge-181717?style=flat&logo=github)](https://github.com/CryptoExplor/Wallet-Forge) [![Live](https://img.shields.io/badge/Live-Vercel-000000?style=flat&logo=vercel&logoColor=white)](https://wallet-forge.vercel.app)

A 100% browser-based utility for importing, validating, cleaning, and exporting private keys and addresses. EIP-55 checksums, real BIP-39 mnemonic verification, multi-chain address detection, zero backend, and zero network requests.

**Stack:** `HTML` `JavaScript` `Web Crypto API` `EVM`
